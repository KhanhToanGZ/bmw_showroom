# BMW Luxury Showroom

Website giới thiệu và cấu hình các dòng xe BMW với giao diện Black & Gold

## Yêu cầu

- Trình duyệt Chrome,Edge,Firefox hoặc Brave
- VS Code (khuyến nghị)
- Extension Live Server

*Cách chạy dự án

1. Tải source code

bash
git clone https://github.com/your-username/bmw-luxury-showroom.git

Hoặc tải file ZIP từ GitHub và giải nén.

2. Mở dự án

Mở thư mục dự án bằng VS Code.

3. Chạy website

Cài đặt extension: Live Server

Sau đó:

Chuột phải vào file index.html
→ Open with Live Server

*Các trang chính

- index.html : Trang chủ BMW Showroom
- configurator.html : Trang cấu hình xe BMW

## Lưu ý

- Đảm bảo giữ nguyên cấu trúc thư mục images, videos,models,css,js.
- Không đổi tên các file tài nguyên để tránh lỗi đường dẫn.
